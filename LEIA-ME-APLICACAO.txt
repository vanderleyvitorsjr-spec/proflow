CORREÇÃO DAS MIGRATIONS DO PROFLOW

1. Feche o servidor com Ctrl + C.
2. Extraia este ZIP na raiz do ProFlow.
3. Aceite substituir os arquivos dentro de prisma/migrations.
4. Não substitua nem envie .env ou .env.local.

Depois execute:

npx prisma migrate resolve --rolled-back 20260711170000_contas_receber_financial_transaction
npm run db:migrate:deploy
npm run db:status
npm run db:generate
Remove-Item -Recurse -Force .next
npm run dev

Não execute:
- prisma db push
- prisma migrate reset

Se `migrate resolve` disser que a migration não está em estado de falha,
execute `npm run db:status` e use o nome exato que aparecer como failed.
