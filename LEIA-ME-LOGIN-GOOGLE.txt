NOVA INTERFACE DE LOGIN E ACESSO COM GOOGLE

Pré-requisitos já configurados:
- Google OAuth habilitado no Supabase;
- Client ID e Client Secret do Google salvos no provedor;
- Site URL: http://localhost:3000;
- Redirect URLs:
  http://localhost:3000/auth/callback
  http://localhost:3000/**

ARQUIVOS INCLUÍDOS

- app/login/page.tsx
- app/login/login-form.tsx
- app/auth/callback/route.ts

COMPORTAMENTO

- Conta já vinculada a um usuário interno:
  abre o Painel normalmente.

- Conta Google autenticada, mas sem vínculo interno:
  o Dashboard redireciona para o onboarding já existente.

- Falha no OAuth:
  retorna para o login com mensagem clara.

- O parâmetro next é validado para evitar redirecionamento externo.

COMO APLICAR

1. Pare o servidor:
   Ctrl + C

2. Extraia este ZIP na raiz do ProFlow e aceite substituir os arquivos.

3. Execute:
   npm run lint
   npx tsc --noEmit
   npm run build

4. Limpe o cache:
   Remove-Item -Recurse -Force .next

5. Inicie:
   npm run dev

6. Abra:
   http://localhost:3000/login

7. Teste primeiro em uma janela anônima.

SEGURANÇA

- Nenhum Client Secret do Google é colocado no código.
- O segredo permanece somente no painel do Supabase.
- O login usa o cliente público do Supabase e callback SSR.
