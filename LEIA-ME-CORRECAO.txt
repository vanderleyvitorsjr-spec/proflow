CORREÇÃO — CONFIGURAÇÕES, PERFIL E APARÊNCIA

Esta correção resolve:

1. Dados antigos da empresa e do Perfil que deixaram de aparecer após a
   implantação das chaves multiempresa.
2. Valores internos em inglês exibidos em Parâmetros Operacionais.
3. Tema, contraste, densidade, fonte, cor de destaque e arredondamento.
4. Uso incorreto do hook do next-themes após a adoção do ThemeProvider próprio.

RECUPERAÇÃO DOS DADOS

Os dados não foram apagados. Eles permaneceram nas chaves antigas:
- proflow:configuracoes:v1
- proflow:perfil:v1

Ao abrir Configurações ou Perfil, a correção copia esses dados para a chave
isolada da empresa autenticada, somente se a nova chave ainda estiver vazia.

A chave antiga não é apagada.

COMO APLICAR

1. Pare o servidor com Ctrl + C.
2. Extraia este ZIP na raiz do ProFlow.
3. Aceite substituir os arquivos.
4. Execute:
   npm run lint
   npx tsc --noEmit
   npm run build
5. Limpe o cache:
   Remove-Item -Recurse -Force .next
6. Inicie:
   npm run dev

Depois:
- abra Configurações;
- confira os dados da empresa;
- abra Perfil;
- teste cada opção em Aparência e clique em Salvar seção.

Não limpe o armazenamento do navegador antes de confirmar a recuperação.
