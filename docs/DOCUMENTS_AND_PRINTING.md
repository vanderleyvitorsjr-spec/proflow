# Documentos, Impressão e Exportação

`ProfessionalDocument` é compartilhado por Orçamento, Ordem e Relatório Técnico.

- Identidade visual usa somente dados configurados; ausentes são omitidos.
- Impressão A4 evita cortes e repete cabeçalhos de tabelas.
- PDF usa a infraestrutura do navegador.
- CSV usa UTF-8 com BOM, separador `;` e neutralização de fórmulas.
- Gerar documento nunca altera pagamento, caixa, Estoque ou status.
