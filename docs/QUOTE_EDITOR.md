# Editor Profissional de Orçamentos

O editor usa o fluxo `Página → Action → Service → Repository → Storage Adapter`.
Itens, valores e condições comerciais são calculados em centavos inteiros. Serviços
do Catálogo entram como cópia independente, portanto alterações no Orçamento não
modificam o serviço original. Materiais não são reservados automaticamente.

O salvamento permanece manual nesta etapa. Essa decisão evita registros duplicados
e mudanças silenciosas de situação enquanto a persistência ainda é local.
